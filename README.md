# 🌦️ Barasat Weather Forecast

A simple, responsive and full-featured weather forecast dashboard focused specifically on **Barasat, North 24 Parganas, West Bengal, India**.

The application combines weather information from multiple providers to provide current conditions, hourly forecasts and upcoming daily forecasts in a single interface.

## 📍 Location

- **City:** Barasat
- **District:** North 24 Parganas
- **State:** West Bengal
- **Country:** India
- **Timezone:** Asia/Kolkata

## 🌐 Weather Providers

The dashboard is designed to use three weather APIs:

1. **Open-Meteo**
   - No API key required for its free non-commercial API
   - Current weather
   - Hourly forecast
   - Daily forecast

2. **WeatherAPI.com**
   - Current weather
   - Hourly forecast
   - Daily forecast
   - Additional weather information depending on the endpoint

3. **Tomorrow.io**
   - Current conditions
   - Hourly forecast
   - Daily forecast

The application can compare data from multiple providers and display provider availability/status.

## ✨ Features

- Current weather conditions
- Feels-like temperature
- Humidity

- Wind speed and direction
- Wind gusts
- Cloud cover
- Precipitation
- Rain probability
- UV information

- 24-hour hourly forecast
- Upcoming multi-day forecast

- Rain/precipitation information
